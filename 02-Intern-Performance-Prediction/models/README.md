# Trained Models

This folder is intended to store the trained machine learning models generated during this project.

The trained model files are **not included** in this repository because some of them exceed GitHub's maximum file size limit.

## Models Generated

The following models and supporting files are automatically generated after running the notebook:

```text
logistic_regression_model.pkl
decision_tree_model.pkl
random_forest_model.pkl
label_encoder.pkl
onehot_encoder.pkl
feature_columns.pkl
```

## How to Generate the Models

Run the Jupyter Notebook:

```text
notebook/Intern_Performance_Prediction.ipynb
```

The notebook will automatically:

- Train all machine learning models
- Evaluate model performance
- Compare the models
- Save the trained models in this folder

No additional steps are required.

---

**Note:** The model files are intentionally excluded from this repository to comply with GitHub's file size limitations.
